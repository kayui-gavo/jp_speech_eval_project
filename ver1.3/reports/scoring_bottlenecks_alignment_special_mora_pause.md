# 四维评分瓶颈：对齐、特殊拍与自然停顿

## 当前结论

| 维度 | 当前能测什么 | 主要瓶颈 | 当前适合程度 |
|---|---|---|---|
| 发音清晰度 | 录音质量、mora 对齐、时长稳定性 | 不是音素 GOP；音素替换基本看不见；equal fallback 会虚高 | 仅粗粒度练习参考 |
| 节奏 / 特殊拍 | mora 时长、长音、拨音等局部时长证据 | 高度依赖边界；促音闭塞和拗音尚不稳定 | 有可靠边界时才可提示 |
| 流畅度 | 语速、长停顿、发声连续性 | 分数上限拥挤；自然句法停顿可能被当成卡顿 | 可识别明显犹豫，不适合细判 |
| 音高变化 | F0 覆盖、范围、局部变化、平坦/随机走势 | 弱参考不能判断唯一重音答案；句末语调允许多种表达 | naturalness 参考，不是严格重音判定 |

## 对齐为什么是共同瓶颈

- 评分和图表都依赖“这一段声音属于哪一拍”。
- MFCC-DTW 能做粗粒度时间映射，但参考音频、说话速度和音素实现差异较大时，局部边界会漂移。
- DTW 边界被健康检查判为不稳定后，runtime 会退回 equal mora。等分可以保证有数字，却会人为制造整齐时长：节奏和发音 proxy 容易虚高，特殊拍证据则失去意义。
- 因此需要把“保证输出数字”和“允许具体纠错”分开。fallback 可以给低置信度整体练习分，但不能支持某一拍太短、某处重音错误等细粒度结论。

## 特殊拍现状

| 类型 | 当前证据 | 风险 | 建议 |
|---|---|---|---|
| 长音 | 相对平均 mora 时长；JVS native false-alarm proxy 约 3.4% | 边界漂移会把长音切给相邻拍；自然语速变化影响比值 | 可靠对齐、远离阈值边缘时，仅提示“可能偏短” |
| 拨音（ン） | 鼻音段相对时长；false-alarm proxy 约 4.6% | /N/ 的实现随音环境变化，单看时长不完整 | 与鼻音/后续辅音声学证据联合后再扩大使用 |
| 促音（ッ） | 期望检测闭塞或摩擦延长 | 当前标签中的显式闭塞样本不足，阈值仍 insufficient | 暂不做正式纠错；需可靠 closure/geminate 特征 |
| 拗音（ャュョ） | 应判断一个 mora 内的辅音滑音组合 | 它不是单纯的“时长长短”问题 | 暂不按时长打分；以后用 phone sequence / posterior |

特殊拍还存在一个统计问题：当前平均 mora 时长的分母包含特殊拍本身。句子中长音或拨音较多时，分母会被它们反向拉动。更稳妥的基线应优先使用同一短语内的普通 mora，并结合前后邻拍，而不是全句一个平均值。

## 自然停顿如何不被误伤

当前 pause detector 将超过约 0.30 秒的低能量段视为长停顿，再按停顿比例和数量扣分。这能抓明显犹豫，但不知道停顿是否位于合理的句法边界。

后续应采用以下约束：

1. **先区分边界停顿与内部卡顿**：标点、文节、accent phrase 或 ASR word boundary 附近的停顿给予更大容忍度。
2. **长度采用连续惩罚**：0.3 秒左右不应突然扣分；只对明显超过同类母语分布的停顿逐渐加重。
3. **句首句尾不计内部停顿**：endpointing 单独处理，避免思考后开口或自然收尾重复扣分。
4. **短句减少停顿结论**：停顿样本太少时只评价连续性，不评价停顿习惯。
5. **疑问、列举和强调允许变化**：不把表达性停顿直接等同于不流畅。
6. **保留可解释证据**：显示“中间出现 0.8 秒静音”比笼统说“不流畅”更可靠；不能确定句法位置时不说“停错地方”。

## 建议的升级顺序

1. 先提升 phone/mora 边界，给每个边界独立置信度。
2. 发音清晰度加入音素级 acoustic/posterior 特征，摆脱纯时长 proxy。
3. 特殊拍先完成长音和拨音的可靠对齐路径；促音、拗音继续 shadow。
4. 流畅度拆成语速、内部犹豫、边界停顿三部分，并按句法位置判断。
5. 最后再用 speaker-disjoint 的 JVS/JANON 与扰动控制检查分布和区分度，避免仅调权重制造好看的数字。

## 本轮已做的显示与评分安全修正

| 问题 | 修正 |
|---|---|
| weak-reference 音高证据不足时，UI/renderer 可能用 raw strict prosody 兜底 | 取消 raw prosody fallback。weak pitch 没有证据时，音高维度显示为不可用，而不是显示调试分 |
| equal/fallback 边界会人为制造整齐 mora 时长，导致发音/节奏 proxy 虚高 | weak-reference 下仍可给练习分，但 fallback 对齐会封顶发音清晰度和节奏维度，并记录 `weak_dimension_adjustments` |
| 分数卡只显示数字，用户看不出该维度证据强弱 | UI 分数卡加入每个维度的判断可信度；不可用维度显示证据不足 |
| 自然短语停顿容易被当成不流畅 | 流畅度加入基于 mora 数的自然停顿容忍度。长句中的少量短语停顿不明显扣分，多次卡顿或停顿比例过高才扣分 |
| 用户录音和示范音高曲线视觉上没有对齐 | 音高图将用户逐帧 F0 通过 MFCC-DTW 映射到示范/参考时间轴；两条线使用同一种折线语法 |

## 仍未解决的核心问题

- 发音清晰度仍不是 GOP/音素后验评分；它只能粗略反映录音清楚、mora 对齐和时长稳定性。
- 特殊拍仍依赖边界质量。长音、拨音可以作为轻提示；促音和拗音不能正式纠错。
- weak-reference 音高是 naturalness，不是严格 pitch accent correctness。OJAD/OpenJTalk 可以做弱提示，不能当唯一正确答案。
- 目前的“低分”仍主要来自规则、扰动控制和无人工标签校准，不应解释为考试级评分。

本报告描述当前瓶颈、已修正的安全边界和后续升级方向。
